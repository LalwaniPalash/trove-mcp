# Trove Promo Video Design

## Goal

Create a short premium promo video for academicians using Claude or similar AI tools for research. The cut can be shorter than 45 seconds if that improves clarity. The video should feel distinctive, fast, and trustworthy instead of resembling a stock Remotion template.

## Positioning

- Trove is an MCP for academic research.
- The key message is not only speed, but trustworthy research workflow support.
- The differentiator is fail-closed behavior: when evidence is weak or unavailable, Trove says so instead of bluffing.

## Audience

Researchers, professors, PhD students, and academic power users using Claude to search papers, compare evidence, and trace ideas.

## Visual Direction

- Single dark "research observatory" theme across the whole film.
- Typography uses a modern geometric display face for headlines and a monospaced systems face for labels and prompts.
- Visual language is orbital, signal-based, and system-oriented: source nodes, scan sweeps, ranked strips, evidence gates, and workflow pulses.
- Motion should be materially faster than the first draft: shorter scene lengths, quicker reveals, and fewer moments lingering on static cards.

## Story Structure

### 1. Hero

Open with a dark observatory-style research interface and a Claude prompt asking Trove to trace an idea. Establish the tone: rigorous academic work without bluffing.

### 2. Discovery

Show multiple scholarly sources converging into a rank-and-dedupe relay and a set of ranked paper strips.

### 3. Reading and Synthesis

Show extracted claims, comparison matrices, and a literature map in one connected synthesis dashboard.

### 4. Trust Layer

Show requests passing through a fail-closed truth gate where `ok`, `partial`, and `unavailable` remain visible instead of being hidden behind fake certainty.

### 5. Workflow

Return to the Claude context and show search, read, compare, and trace as a fast research pipeline.

### 6. Outro

Land on the core verbs and a simple install cue.

## Planned Copy

- "Research without bluffing."
- "Search the research graph."
- "Turn papers into structure."
- "Weak evidence stays visible."
- "Research inside Claude."
- "Search. Read. Compare. Trace."
